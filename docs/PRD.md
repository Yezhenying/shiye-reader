## 1. 文档目的

本文把当前 Demo 中分散、冲突或不符合用户习惯的功能，收敛为一套可实施、可验收的产品需求。目标不是复制微信读书的视觉或商业功能，而是借鉴其桌面端最有价值的使用心智：**从书架进入阅读、阅读上下文持续存在、目录/正文/笔记按需展开、操作结果及时反馈、阅读进度可跨会话恢复**。

## 2. 背景与现状

### 2.1 当前已有能力

当前 React Demo 已包含：

- 今日阅读、书架、全部笔记、精彩划线、统计、设置等主导航；
- EPUB、PDF、TXT、Markdown 的基础文本提取；
- MOBI/AZW3 文件识别（尚不能解析正文）；
- OpenLibrary 书目搜索与手动降级；
- 本地笔记、标签、笔记类型和简单表达优化；
- 阅读预览、随机回顾、Markdown 导出；
- 日间/夜间主题与响应式布局。

### 2.2 当前核心矛盾

1. **导入不等于真正入库**：只把截断正文和元数据写入 localStorage，原文件、章节和完整阅读位置不能可靠恢复。
2. **书架与阅读断开**：导入后缺少明确的“打开阅读”，首页正在阅读、进度和统计仍有硬编码数据。
3. **阅读与笔记断开**：笔记不能可靠记录章节、页码、选区和原文上下文。
4. **反馈与后续动作不足**：导入成功后没有稳定的“立即阅读 / 完善信息 / 继续导入”闭环。
5. **状态不可管理**：书籍、笔记缺少编辑、删除、排序、去重和恢复操作。
6. **设置名不副实**：目前只有主题切换可操作，其余设置只是状态展示。
7. **桌面习惯不统一**：全局搜索、页面内筛选、返回行为、弹窗焦点、快捷键和阅读面板没有统一规则。

## 3. 产品定位

### 3.1 一句话定义

拾页是一款在浏览器本地保存电子书、阅读进度、划线与笔记的桌面阅读工具，帮助用户完成“导入—阅读—记录—整理—回顾—导出”的完整闭环。

### 3.2 目标用户

**v1 首要用户**：拥有合法、无 DRM 的本地电子书，重视划线笔记和阅读位置连续性的桌面读者。

次要用户包括：

- 在电脑上阅读 EPUB、PDF、TXT、Markdown 的个人用户；
- 需要摘录、思考和写读书笔记的知识工作者或学生；
- 重视本地隐私，不希望文件默认上传云端的用户；
- 希望降低记录阻力，又保留深度思考过程的用户。

### 3.3 设计原则

1. **阅读优先**：阅读器中的正文永远是视觉中心，工具按需出现。
2. **上下文连续**：从书架到阅读、从划线到笔记、从关闭到恢复都保持同一上下文。
3. **渐进披露**：默认只展示当前任务需要的信息，高级设置在二级入口。
4. **操作可撤销**：删除、覆盖、批量操作和自动润色必须可确认、可撤销或保留原文。
5. **本地优先**：文件、进度、划线和笔记默认仅保存在本机。
6. **状态真实**：首页、统计和进度全部来自真实数据，不允许用演示数字冒充用户数据。
7. **格式诚实**：区分“可完整阅读”“可提取文本”“仅识别入库”，不笼统宣称完全兼容。
8. **借鉴而不照搬**：采用微信读书式桌面阅读心智，不复制其品牌、内容、社交和商业界面。

## 4. 产品目标与非目标

### 4.1 v1 目标

- 用户可可靠导入一本合法持有的 EPUB/PDF/TXT/MD 文件并在刷新后继续阅读；
- 用户可从书架一键进入阅读器，并恢复到上次位置；
- 用户可在阅读器中查看目录、搜索当前书正文、添加书签、划线并创建带位置的笔记；
- 用户可管理书籍和笔记，真实查看进度与统计；
- 用户可导出“完整可阅读备份”，并恢复原文件和全部业务数据；
- 桌面端 1366×768 到 2560×1440 通过质量规范中的视口任务检查；
- 离线资源准备完成后，断网冷启动仍可导入、阅读、搜索当前书、划线、写笔记和导出；Chrome/Edge/Safari 走已安装 PWA 系统入口，Firefox 桌面走同源书签/URL 的离线浏览器冷启动；在线书目和远程封面除外。

### 4.2 v1 非目标

- 不实现正版内容商城、付费阅读、好友排行、评论社区和听书；
- 不绕过 DRM，不承诺解析加密 EPUB/PDF/MOBI/AZW3；
- 不默认上传用户电子书或笔记；
- 不在 v1 实现账号体系和跨设备实时同步；
- 不将本地规则润色宣传为大模型能力；
- 不内置来源不明或未经授权的完整电子书。

## 5. 信息架构

### 5.1 一级导航

| 导航 | 作用 | 默认内容 |
|---|---|---|
| 今日阅读 | 继续最近阅读与今日概览 | 最近一本在读书、今日时长、最近笔记 |
| 我的书架 | 管理电子书 | 在读、想读、搁置、读完、全部；v1 默认封面网格 |
| 全部笔记 | 浏览与管理笔记 | 按更新时间倒序，支持筛选和批量导出 |
| 精彩划线 | 查看原文摘录 | 按书籍、章节、颜色、时间筛选 |
| 阅读统计 | 真实阅读数据 | 时长、天数、书籍、笔记；v1 不含热力图 |
| 回顾（P1，v1 不进入一级导航） | 间隔重复和随机回顾 | 今日待回顾、已完成、稍后提醒 |
| 设置 | 外观、阅读、导入、数据和隐私 | 可操作控件，不展示伪状态 |

### 5.2 全局顶栏

- 全局搜索（P0）：搜索书名、作者、ISBN、笔记和标签；快捷键 `Ctrl/Cmd + K`。当前书正文搜索位于阅读器内；跨全书库正文索引属于 P1。
- 导入：在书架和全局均可进入，但书架页面的导入按钮是主入口。
- 新建笔记：全局创建“随手记”；若在阅读器内，则默认关联当前书和当前位置。
- 用户/存储状态：v1 显示本地模式及存储健康状态，不伪装成账号头像。

### 5.3 阅读器工作区

桌面端采用可折叠三栏：

```text
┌──────────────────────────────────────────────────────────────┐
│ 返回书架  书名/章节      搜索  显示设置  书签  更多          │
├──────────────┬──────────────────────────┬────────────────────┤
│ 目录/书签     │                          │ 划线与笔记          │
│ 220–280 px   │ 正文 640–820 px          │ 280–360 px         │
│ 可折叠        │ 始终居中                 │ 可折叠              │
└──────────────┴──────────────────────────┴────────────────────┘
```

- 默认只展开目录；用户打开笔记时右栏出现。
- 左右栏状态按书保存。
- 窗口不足 1100px 时，侧栏改为覆盖抽屉，不挤压正文。
- 阅读正文默认宽度 720px，可在 600–880px 范围内调整。

## 6. 核心用户流程

### 6.1 本地文件导入

1. 用户在书架点击“导入电子书”。
2. 默认进入“本地文件”页签，可选择或拖入文件。
3. 系统校验格式、大小、重复文件和存储容量。
4. 系统后台解析元数据、目录、正文、封面和页数。
5. 若检测到重复书籍，提供：打开已有、替换文件、保留副本、取消。替换前展示受影响的进度/书签/划线/笔记数量；用户选择保留旧版、尽力重定位、解除位置关联或取消。
6. 解析成功后显示可编辑元数据、文件规模及解析能力标签。
7. 用户选择：立即阅读、完善信息、继续导入。
8. 文件和解析批次先进入不可见 staging；最终发布事务完成后才提示“已导入”。
9. 默认软限制 100MB；超过后根据 `storage.estimate()` 的可用配额给出风险确认。硬上限和解压安全上限由技术/质量规范定义。

#### 格式能力文案

| 格式 | v1 能力 | 用户文案 |
|---|---|---|
| EPUB（流式） | HTML/XHTML 正文、目录、链接、常见图片/SVG/字体和稳定位置；脚本、媒体覆盖、MathML、竖排/RTL 按能力降级 | 支持流式阅读（不含 DRM） |
| EPUB（固定版式） | P1；v1 识别后保留原文件并提示尚未支持阅读 | 可保存，固定版式阅读将在后续提供 |
| PDF（文字型） | 原始页面、文本层、页码、搜索 | 支持阅读与文字提取 |
| PDF（扫描型） | 原始页面；无文本时提示 OCR 不可用 | 支持查看，暂不支持文字搜索 |
| TXT | UTF-8/GB18030 编码检测与手动切换 | 支持阅读 |
| MD | Markdown 渲染、标题目录 | 支持阅读 |
| MOBI/AZW3 | 文件入库与元数据，正文不解析 | 可保存，暂不支持正文阅读 |

### 6.2 在线书目导入（可选 P1，不阻塞 v1）

- 在线搜索仅导入封面、作者、年份、ISBN 等元数据，不暗示包含正文。
- OpenLibrary 请求超过 8 秒进入可重试状态；允许手动录入。
- 若书架已有同 ISBN 或相同标题+作者，提示合并而非重复添加。
- 在线书目没有正文时，书籍状态为“仅书目”，主按钮为“添加本地文件”，不是“开始阅读”。

### 6.3 从书架开始阅读

1. 书架默认按“最近打开”排序。
2. 单击书籍卡片进入详情/快速操作，双击或点击“继续阅读”直接进入阅读器。
3. 有历史进度时恢复到最后位置；无进度时进入封面后第一个正文章节。
4. 位置在切换章节时立即保存，滚动中每 5 秒节流保存；`pagehide` 仅作补充，不作为唯一保存机会。
5. 恢复验收：EPUB/TXT/MD 回到同一语义段落（目标锚点前后不超过 120 个字符）；PDF 回到同一页且页内进度误差不超过 5%。
6. 返回书架后，该书移动到最近位置；首页“正在阅读”同步更新。

### 6.4 划线与笔记

1. 用户选中文字后出现轻量工具条：划线、写想法、复制。
2. 用户可在未选中文字时添加书签；书签记录当前章节/页码和位置，可选填备注。
3. “划线”立即保存选区、颜色、章节、位置和前后文摘要。
4. “写想法”在右栏打开编辑器，默认关联当前划线。
5. 笔记类型：感悟、摘录、问题、行动；书签作为独立轻量对象管理。
6. 摘录正文永不自动润色；P0 只提供标点/空白等基础格式修正；专业/深度语义润色属于 P1。
7. 任何修正都必须展示原文与结果，并提供“采用、继续编辑、恢复原文”。
8. 保存后右栏立即出现；关闭并重新打开书籍后位置关系仍有效。

### 6.5 笔记与删除管理

- 卡片单击进入详情，支持编辑、删除、复制链接标识、导出。
- 删除先进入 30 天回收站；回收站可恢复或彻底删除。
- 筛选条件以可见筛选条展示，不允许用户因隐藏搜索条件误以为数据丢失。
- 标签可创建、重命名、合并和删除。
- 新笔记的分类由用户选择或继承书籍分类，不再固定写入“随手记”。
- 时间存储为 ISO 时间戳，界面动态计算“刚刚/昨天/日期”。
- 书籍与笔记均进入 30 天回收站。删除书籍时默认勾选“保留笔记与划线”，原文件保留 30 天；若用户取消保留，笔记/划线随书进入同一回收站 generation，可整体恢复。来源书被删除但内容保留时，笔记继续显示快照和“来源不可用”，恢复或重新关联同指纹文件后恢复定位。
- 彻底删除前展示将移除的原文件、章节、进度、书签、划线和笔记数量；若选择保留笔记，则只解除文件/位置关联。
- 替换拆成三步：①重复文件主动作（打开已有/替换/保留副本/取消）；② locator 策略（尽力重定位/解除关联/取消）；③旧版本策略（默认保留至用户确认重定位，最长 30 天，可立即清理）。

### 6.6 回顾（P1，不阻塞 v1）

- P1 提供“今日待回顾”和随机回顾。
- 默认间隔：1、3、7、14、30 天；用户反馈“记得 / 模糊 / 忘记”后调整下一次日期。
- 回顾卡显示笔记内容、来源书籍和章节；先隐藏用户原来的思考，点击后揭示。
- 可以稍后提醒或从回顾中打开原书位置。

### 6.7 数据备份与恢复

- 设置中提供两种备份：①默认“完整可阅读备份”，包含所有权威用户数据：当前及保留期内旧版原文件、canonical rendition/章节资源、封面、书目、进度、书签、笔记、冲突草稿/修订、划线、标签、分类、阅读会话、回顾数据、设置和回收站；②“轻量数据备份”，不含原文件/派生正文，并明确恢复后需要重新关联文件才能阅读。
- 导出前展示预计大小、包含范围和恢复能力。
- 恢复前展示内容统计；冲突按书/笔记分别支持跳过、覆盖、保留副本、按更新时间合并，并保证 ID/引用一起重映射。
- 恢复使用不可见 staging；校验失败不覆盖现有数据。
- Markdown 导出必须明确是“当前筛选结果”还是“全部笔记”。

## 7. 功能需求

### 7.1 P0：必须完成

| ID | 需求 | 验收要点 |
|---|---|---|
| P0-01 | IndexedDB 持久化 | 刷新和重启浏览器后原文件、进度、笔记可恢复 |

| P0-04 | PDF 阅读 | 原始页面、文本层、链接/已有注释展示、无障碍层（源文件具备时）、页码和位置可恢复；不执行脚本/Launch，不编辑表单/附件 |
| P0-05 | TXT/MD 阅读 | 编码处理、Markdown 渲染和标题目录可用 |
| P0-06 | 真实首页与基础统计 | 最近阅读、进度、今日时长、连续天数和近 7 日每日阅读分钟柱状图来自本地数据；空数据为 0/空状态 |
| P0-07 | 笔记与标签管理 | 笔记创建/打开/编辑/删除/恢复/关联位置；标签创建、重命名、合并、删除且引用一致 |
| P0-08 | 划线 | 创建、颜色、定位、删除、转笔记 |
| P0-09 | 设置生效 | 阅读字号、行距、宽度、主题等即时预览并持久化 |
| P0-10 | 导入闭环 | 成功、失败、重复、容量不足、取消均有正确下一步 |
| P0-11 | 路由和返回 | 刷新、前进、后退保持页面/书籍上下文 |
| P0-12 | 数据备份 | 能导出、校验并恢复完整业务数据 |
| P0-13 | 书签 | 可添加、定位、备注、删除并跨会话恢复 |
| P0-14 | 当前书正文搜索 | EPUB/TXT/MD/PDF 文本层可搜索并定位；扫描 PDF 明确降级 |
| P0-15 | 离线冷启动 | 显示“离线资源已就绪”后无需预热：可安装浏览器从 PWA 系统入口、Firefox 从同源 URL 冷启动；均可断网导入任一 P0 格式并完成全部本地 P0 流程 |
| P0-16 | 全局业务搜索 | 搜索书名、作者、ISBN、笔记和标签并打开目标；不包含全库正文 |

### 7.2 P1：重要增强

- 跨全部书籍的正文索引和统一搜索结果页；
- EPUB 固定版式阅读（缩放、单双页、方向、目录；选区注释另行评估）；
- 笔记批量操作和按书导出；
- 回顾计划与阅读热力图（哪些笔记进入回顾、退出、编辑/删除后的重排在实施 PRD 中定义）；
- 书架列表视图和自定义分组；P0 仅提供默认封面网格与状态筛选；
- 自动关联相似笔记（先采用本地关键词，不强依赖云 AI）；
- 在线书目/远程封面补全；
- 专业/深度语义润色；P0 只要求原文保留、基础格式修正和用户确认；
- 可选 OCR 扩展入口；
- 快捷键中心。

- 听书和语音笔记；

## 8. 页面级需求

### 8.1 今日阅读

- 首屏只保留一个明确主动作：“继续阅读《书名》”。
- 当前书、进度、最近章节、上次阅读时间均由数据计算。
- 没有书时显示导入引导；有书无进度时显示“开始阅读”。
- 今日统计仅显示真实数据；不足一天不制造连续阅读记录。
- 最近笔记支持打开详情，不只是静态卡片。

### 8.2 我的书架

- 默认内容最大宽度随桌面伸展至 1560px。
- 1366px 显示 4–5 个封面位，1920px 显示 6–8 个；不采用信息拥挤的小卡片。
- 默认“封面网格”只展示封面、书名、作者、进度；详细状态进入列表模式或详情抽屉。
- 顶部提供状态筛选、排序和导入；列表/网格切换属于 P1。
- 空状态、无搜索结果、解析失败、存储不足分别设计。

### 8.3 阅读器

- 正文不受全局侧边栏宽度影响，进入沉浸式独立路由。
- 顶栏在静止 3 秒后弱化，鼠标移动或键盘操作后恢复。
- 目录、书签、划线、笔记共享左/右侧面板容器。
- 阅读设置即时应用，不刷新正文位置。
- PDF 与流式文本使用不同渲染器，但共享进度和笔记接口。

### 8.4 设置

分组如下：

1. 外观：日间/夜间/暖色/跟随系统、界面字号、密度、减少动画；
2. 阅读：字体、字号、行距、段距、正文宽度、滚动/分页方式；全局默认与单本覆盖分开保存；
3. 导入：默认重复策略、TXT 编码、文件大小提示；
4. 笔记：默认类型、润色级别、自动保存；
5. 回顾（P1）：每日数量、默认间隔、通知；
6. 数据：占用空间、备份、恢复、清理回收站；
7. 隐私：本地处理说明、外部元数据/封面请求开关；
8. 快捷键与关于。

所有设置项必须是可操作控件；尚未实现的功能不以“已开启”伪装。

## 9. 统一交互规则

### 9.1 导航与返回

- 一级页面有稳定 URL；阅读器 URL 至少包含 `bookId`。
- 浏览器返回等价于界面返回，不关闭或丢失未保存内容。
- 笔记默认 500ms 防抖自动保存草稿；状态显示“保存中/已保存/保存失败”。返回前强制 flush；失败时保留内存与草稿副本并提供复制，不以卸载时写入作为唯一保障。

### 9.2 搜索与筛选

- 全局搜索输入 250ms 防抖；`Enter` 打开完整结果。
- 搜索条件始终显示在结果头部，并提供一键清除。
- 页面切换时保留全局查询，但必须显示“正在搜索：关键词”；局部筛选按页面独立保存。

### 9.3 反馈

- 小操作成功使用短 Toast；重要结果在页面内展示，不只依赖 Toast。
- 超过 400ms 的操作显示加载状态；超过 8 秒提供取消或降级。
- 错误消息回答三件事：发生什么、数据是否安全、下一步做什么。
- 禁止在真实写入完成前提示“已保存/已导入”。

### 9.4 删除

- 单条可恢复删除：Toast 提供“撤销”。
- 批量删除、清除回收站、删除原文件：二次确认并显示影响范围。
- 删除书籍时可选择是否保留笔记和划线。

### 9.5 多标签页

- v1 支持多个阅读标签页，但同一笔记同一时间只允许一个活动编辑租约；其他标签页显示只读和“接管编辑”。
- 进度按 `updatedAt + revision` 合并，较新稳定 Locator 生效；设置、书架和删除通过 `BroadcastChannel` 失效通知同步。
- 发生版本冲突时保留双方草稿，不静默覆盖。

### 9.6 键盘

- `Ctrl/Cmd + K`：全局搜索；
- `Ctrl/Cmd + O`：导入文件；
- `Ctrl/Cmd + N`：新建笔记；
- `[` / `]`：上一章/下一章（输入框聚焦时无效）；
- `Esc`：关闭最上层浮层或退出沉浸工具；
- `?`：快捷键帮助。

## 10. 数据与统计口径

- 阅读时长：页面可见且阅读器激活时累计；任一滚动/翻页/键盘/选区活动把 `lastActiveAt` 更新为当前时间。自最后活动起前 60 秒计入活跃时长，第 61 秒起暂停累计；“5 分钟”仅用于结束并落盘会话，不补计空闲区间。
- 今日阅读：按本地时区自然日计算。
- 连续阅读：当日有效阅读不少于 1 分钟，或完成至少一次划线/笔记。
- 阅读进度展示公式：EPUB/TXT/MD =（已完成章节权重 + 当前章节字符 progression）/ 全书可读字符权重；PDF =（pageNumber-1 + pageProgression）/ 总页数；统一限制 0–100%。Locator 仍是恢复真值，百分比只用于展示。
- 阅读状态：本地文件导入默认为“想读”，仅书目也为“想读”；首次打开自动转为“在读”；用户可手动设为想读/在读/搁置/读完并可撤回。进度达到 98% 只提示确认，不自动强制读完。
- 多标签页阅读时长按时间区间并集去重，同一用户同一时刻最多累计 1 秒；由跨标签页 activity leader lease 汇总。
- 基础图表固定为“近 7 个本地自然日每日有效阅读分钟”，无会话显示 0，不用演示占位值。
- 笔记数量：不含回收站；划线与笔记分别统计。

## 11. 成功指标

指标分为三类，详细样本、分母和发布判定见质量规范：

1. **自动化发布门禁**：支持格式 fixture 导入成功率 100%（正向集合）；1000 次位置恢复成功率 ≥ 99.9%；1000 次模拟笔记提交在无故障环境下成功率 100%，故障注入时草稿保留率 100%。
2. **可用性研究指标**：至少 10 名首要用户执行统一任务脚本，“导入—打开—划线—写笔记—刷新恢复”无协助完成率 ≥ 90%；导入成功后 60 秒内找到并启动阅读的比例 ≥ 90%。
3. **产品观察指标（不作为 v1 发布门禁）**：在用户明确同意匿名遥测后统计真实使用中的导入、续读和笔记行为；默认关闭且不上传正文、书名或笔记。纯本地个人统计不能用来推断总体成功率。

桌面主要流程必须无未修复的 S0/S1/S2。

## 12. 里程碑

### M1：可靠书架与数据底座

- 范围：P0-01、P0-02、P0-06、P0-10、P0-12、P0-15 的数据/PWA 基础；
- 退出：迁移、配额、书籍 CRUD、删除/恢复、完整备份恢复和断网冷启动通过阶段门禁。

### M2：桌面阅读器

- 范围：P0-03、P0-04、P0-05、P0-09、P0-11、P0-13、P0-14；
- 退出：流式 EPUB、PDF、TXT/MD、目录、书签、位置恢复、当前书搜索、设置和路由通过阶段门禁。

### M3：划线与笔记闭环

- 范围：P0-07、P0-08、P0-16，并完成 P0-12 的笔记/划线备份覆盖；
- 退出：选区、划线、带位置笔记、详情、回收站、全局业务搜索和导出通过阶段门禁。

### M4：v1 发布收口

- 范围：全部 P0 的跨模块验收、真实统计、性能、无障碍和兼容性；
- 退出：质量规范 Beta/Stable 门禁通过。回顾计划、热力图、全库正文索引和固定版式 EPUB 属于 P1，不阻塞 v1。

## 13. 产品决策记录

| 决策 | 结论 | 原因 |
|---|---|---|
| 是否复制微信读书 | 否，只借鉴核心桌面心智 | 避免品牌与商业功能偏移，保持本地阅读定位 |
| v1 是否上云 | 否 | 先解决本地数据可靠性和完整闭环 |
| 是否支持 DRM | 否 | 合规和技术边界 |
| MOBI/AZW3 是否称“支持阅读” | 否 | 当前只能识别入库，必须真实披露能力 |
| 是否自动润色摘录 | 否 | 摘录必须保持原文准确性 |
| 文件存储位置 | IndexedDB | 适合较大结构化数据和 Blob，localStorage 仅保留小型偏好 |
| v1 产品形态 | PWA-first Web Desktop | Chrome/Edge/Safari 可安装；Firefox 桌面以离线浏览器冷启动提供同等核心能力，不虚构系统安装入口 |
| 固定版式 EPUB | P1 | 收窄 v1，优先可靠完成流式阅读闭环 |
| 回顾/热力图 | P1 | 不阻塞核心导入—阅读—笔记流程 |
| 外部元数据和封面 | 默认关闭自动请求 | 用户主动在线搜索即视为本次查询同意；远程封面需单独允许并缓存为本地 Blob |
